# Danglr

랩탑을 일정 시간 건드리지 않으면 화면 위쪽에서 실을 타고 픽셀 캐릭터가 내려오는 데스크톱 앱입니다.

## 다운로드

[**Releases**](https://github.com/mzzz00/Danglr/releases/latest) 페이지에서 운영체제에 맞는 파일을 받아주세요.

- **macOS**: `Danglr-x.x.x-arm64.dmg`
- **Windows**: `Danglr Setup x.x.x.exe`

## 설치 시 경고창이 뜨는 경우

이 앱은 정식 배포용 인증서로 서명되어 있지 않아서(개인이 만든 무료 프로그램이라 인증서 비용 문제로), macOS와 Windows에서 보안 경고가 뜰 수 있습니다. 아래대로 진행하면 정상적으로 설치/실행할 수 있습니다.

### macOS

**"Apple이 확인할 수 없기 때문에 열 수 없습니다" 라고 뜨는 경우**

1. `Danglr.app`을 **마우스 우클릭(또는 control + 클릭)** → **열기** 선택
2. 뜨는 창에서 다시 **열기** 클릭

(그냥 더블클릭하면 계속 막히니, 꼭 우클릭 → 열기로 처음 한 번만 실행해주세요.)

**"손상되었기 때문에 열 수 없습니다"라고 뜨는 경우**

브라우저로 받은 파일에 macOS가 자동으로 붙이는 격리(quarantine) 표시 때문입니다. 터미널을 열고 아래 명령어를 입력해주세요 (Applications 폴더에 설치했다고 가정):

```bash
xattr -cr /Applications/Danglr.app
```

그 다음 위의 "마우스 우클릭 → 열기" 방법으로 실행하면 됩니다.

만약 위 방법으로도 안 열리면, **시스템 설정 → 개인정보 보호 및 보안**으로 들어가서 화면 아래쪽에 "Danglr이(가) 차단되었습니다" 같은 메시지 옆의 **열기** 버튼을 눌러주세요.

### Windows

**"Windows에서 PC를 보호했습니다" (SmartScreen) 경고가 뜨는 경우**

1. 창에 있는 **추가 정보** 클릭
2. 아래에 나타나는 **실행** 버튼 클릭

이후 설치가 정상적으로 진행됩니다.
